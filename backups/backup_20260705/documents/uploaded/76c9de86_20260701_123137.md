## 1. 短视频制作全流程

### 1.1 整体流程图

```
选题策划 → 脚本撰写 → 素材准备 → 拍摄 → 粗剪 → 精剪 → 调色/音效 → 封面制作 → 审核 → 发布 → 数据分析 → 迭代优化
```

### 1.2 各环节详解

#### 第一阶段：选题策划（1-2小时/条）

**核心原则：数据驱动 + 创意灵感**

**操作步骤：**
1. **热点追踪**
   - 抖音热榜 / 快手热榜 / 微博热搜
   - 新榜 / 飞瓜数据 / 蝉妈妈（付费工具）
   - 关注行业 KOL 的最新内容

2. **选题方向**
   - 蹭热点：结合时事/节日/流行语
   - 痛点解决：针对目标用户的实际问题
   - 知识分享：垂直领域的干货输出
   - 情感共鸣：引发用户情绪反应
   - 娱乐搞笑：轻松有趣的内容

3. **选题验证**
   - 搜索同类内容，评估竞争度
   - 查看搜索结果的数据表现（点赞/评论/转发）
   - 确定差异化角度

**产出物：** 选题清单 + 差异化分析

#### 第二阶段：脚本撰写（1-2小时/条）

**短视频脚本结构：**

```
【开头黄金3秒】→ 吸引注意力
【主体内容】→ 传递核心价值（15-45秒）
【结尾引导】→ 点赞/关注/评论引导（3-5秒）
```

**脚本模板：**

| 字段 | 说明 | 示例 |
|------|------|------|
| 标题 | 吸引点击 | "3个技巧让你一天学会剪辑" |
| 时长 | 预计视频长度 | 45秒 |
| 场景 | 拍摄地点 | 书房/户外/工作室 |
| 画面 | 镜头描述 | 近景讲解+屏幕录制 |
| 台词 | 口播内容 | 逐字稿或要点 |
| 字幕 | 关键信息标注 | 重点词汇高亮 |
| BGM | 背景音乐 | 轻快/紧张/温馨 |
| 特效 | 需要添加的效果 | 转场/贴纸/动效 |
| CTA | 行动号召 | "关注我，下期更精彩" |

**写作技巧：**
- 标题公式：数字法（3个技巧）+ 痛点法（别再犯这个错误）+ 悬念法（99%的人不知道）
- 开头必须在前3秒抓住注意力
- 语言口语化，避免书面表达
- 每条视频只讲一个核心观点

#### 第三阶段：拍摄（2-4小时/条）

**拍摄前准备：**
1. 检查设备电量、存储空间
2. 确认光线条件（自然光/补光灯）
3. 准备道具、背景布
4. 调试麦克风
5. 试拍一段检查画面

**拍摄要点：**
- **光线**：正面光最佳，避免逆光；使用柔光箱减少阴影
- **构图**：三分法、中心构图；保持水平线
- **收音**：安静环境，使用领夹麦/指向麦
- **稳定性**：使用三脚架/稳定器
- **多角度**：同一段内容拍2-3遍，不同景别

**常见景别：**
- 全景：展示环境和整体动作
- 中景：半身，适合讲解
- 近景：面部表情，适合情感表达
- 特写：细节展示，适合产品展示

#### 第四阶段：剪辑（2-3小时/条）

**剪辑流程：**

```
导入素材 → 粗剪（筛选）→ 精剪（节奏）→ 加字幕 → 加BGM → 加特效 → 导出
```

**粗剪（筛选）：**
- 删除废片、NG镜头
- 按脚本顺序排列素材
- 控制每条片段时长

**精剪（节奏）：**
- 添加转场效果（淡入淡出/切换/闪白）
- 调整节奏：快剪（紧张感）vs 慢剪（抒情）
- 添加画中画、分屏效果
- 关键帧动画（缩放/平移）

**字幕处理：**
- 自动生成字幕（剪映/PR字幕功能）
- 校对修正错别字
- 设置字幕样式（字体/颜色/位置）
- 重点词语高亮/放大

**BGM选择：**
- 根据内容情绪选择
- 音量控制在人声的20-30%
- 注意版权问题，使用免版权音乐
- 卡点剪辑（配合音乐节拍切换画面）

**导出设置：**
- 格式：MP4 (H.264)
- 分辨率：1080p（竖版1080x1920）
- 帧率：30fps（口播）/ 60fps（运动）
- 码率：8-12 Mbps

#### 第五阶段：审核与发布（30分钟）

**发布前检查清单：**
- [ ] 画质清晰无模糊
- [ ] 音质正常无杂音
- [ ] 字幕准确无误
- [ ] BGM音量合适
- [ ] 无敏感内容/违规词
- [ ] 封面图吸引人
- [ ] 标题有吸引力
- [ ] 标签/话题选择正确

**发布时机：**
- 抖音：中午12:00-13:00 / 晚上18:00-21:00
- 快手：中午12:00-13:00 / 晚上19:00-22:00
- 视频号：早上7:00-8:00 / 中午12:00-13:00 / 晚上20:00-22:00

## 2. 中长视频制作流程

### 2.1 整体流程

```
选题调研 → 深度脚本 → 分镜头设计 → 拍摄（1-3天）→ 粗剪 → 精剪 → 调色 → 音效设计 → 包装 → 审核 → 发布 → 运营
```

### 2.2 各环节详解

#### 选题调研（半天）

**中长视频选题特点：**
- 深度大于广度
- 信息密度高
- 需要提供独特视角或深度分析

**调研方法：**
1. 搜索同类优质视频，分析其优缺点
2. 收集相关数据和案例
3. 确定视频的核心论点/故事线
4. 预估时长（B站8-20分钟，YouTube 10-30分钟）

#### 深度脚本（1-2天）

**中长视频脚本结构：**

```
【Hook】（0-30秒）→ 制造悬念/提出问题
【引言】（30秒-1分钟）→ 交代背景/预告内容
【主体】（1-8分钟）→ 分层展开/案例佐证
【高潮】（最后1分钟）→ 核心观点/情感升华
【结尾】（最后30秒）→ 总结/互动引导
```

**脚本撰写技巧：**
- 使用"总-分-总"结构
- 每3-5分钟设置一个"钩子"留住观众
- 穿插案例、数据、故事增加可信度
- 预留视觉化空间（哪些内容适合画面展示）

#### 分镜头设计（半天）

**分镜头表格式：**

| 镜头号 | 画面描述 | 景别 | 时长 | 台词 | 备注 |
|--------|---------|------|------|------|------|
| 01 | 主持人面对镜头 | 中景 | 15s | "大家好，今天我们..." | 开场 |
| 02 | 屏幕录制演示 | 特写 | 30s | 画外音 | 需要标注 |
| 03 | 案例图片展示 | 全景 | 10s | 画外音 | 加动画效果 |

#### 拍摄（1-3天）

**中长视频拍摄特点：**
- 可能需要多个场景/角度
- 重视画面质量
- 可能需要外景拍摄
- 注意音频质量（建议使用专业麦克风）

**拍摄清单：**
- [ ] 主机位（主持人/主讲人）
- [ ] 辅机位（特写/反应镜头）
- [ ] 屏幕录制素材
- [ ] B-roll（空镜/场景切换）
- [ ] 图片素材/图表
- [ ] 现场音效

#### 后期制作（1-2天）

**剪辑要点：**
- 节奏控制：每30-60秒切换一个画面元素
- 信息密度：适当添加字幕、图表、标注
- 视觉多样性：真人出镜 + 屏幕录制 + 素材混剪
- 章节标记：长视频添加章节导航

**调色：**
- 统一色调风格
- 肤色还原
- 增强对比度和饱和度

**音效设计：**
- 背景音乐（根据段落情绪变化）
- 音效（转场音效、强调音效）
- 环境音（增加真实感）

## 3. 专业视频制作流程

### 3.1 整体流程

```
前期筹备（1-4周）→ 中期拍摄（1-7天）→ 后期制作（1-4周）→ 交付验收
```

### 3.2 前期筹备

#### 项目立项
- 明确视频目的（品牌宣传/产品推广/教育培训）
- 确定目标受众
- 制定预算和时间表
- 组建制作团队

#### 创意开发
- 创意头脑风暴
- 撰写创意提案（含参考样片）
- 确定视频调性（风格/色彩/音乐方向）
- 客户确认创意方向

#### 剧本撰写
- 故事大纲
- 分场景剧本
- 对白撰写
- 拍摄脚本（含镜头指示）

#### 分镜头脚本（Storyboard）
- 手绘或数字绘制每个镜头
- 标注运镜方式（推/拉/摇/移）
- 标注演员走位
- 标注特殊效果

#### 选角与勘景
- 演员试镜/选定
- 拍摄场地勘察
- 确认场地许可
- 准备道具和服装

#### 拍摄计划
- 拍摄日程表（Shot List）
- 人员分工表
- 设备清单
- 应急预案

### 3.3 中期拍摄

#### 设备配置
- 摄影机（电影机/广播级摄像机）
- 镜头组（广角/标准/长焦/微距）
- 灯光设备（主灯/辅灯/轮廓灯/环境灯）
- 录音设备（枪麦/领夹麦/调音台）
- 稳定设备（三脚架/滑轨/稳定器/摇臂）

#### 现场工作流程
1. 布光 → 2. 机位设置 → 3. 试拍检查 → 4. 正式拍摄 → 5. 素材备份

#### 注意事项
- 每天拍摄结束后立即备份素材
- 场记单记录每个镜头的信息
- 监看回放确认质量
- 保持与客户的沟通

### 3.4 后期制作

#### 剪辑（1-2周）
- 素材整理和分类
- 粗剪（搭建结构）
- 精剪（调整节奏）
- 客户初审

#### 调色（3-5天）
- 一级调色（曝光/白平衡/对比度）
- 二级调色（局部调整/风格化）
- 色彩匹配（不同机位/场景的一致性）

#### 音效制作（3-5天）
- 对白清理和增强
- 背景音乐选择和混音
- 音效设计和添加
- 空间声场设计

#### 特效与包装（3-7天）
- 片头/片尾设计
- 字幕和图形包装
- 视觉特效（合成/跟踪/粒子）
- 转场效果

#### 交付
- 多版本输出（横版/竖版/不同平台规格）
- 质量检查
- 客户终审
- 最终交付

## 4. AI辅助视频制作工作流

### 4.1 AI在视频制作中的应用

| 环节 | AI工具 | 功能 |
|------|--------|------|
| 选题策划 | ChatGPT/Claude/文心一言 | 热点分析、选题建议、标题优化 |
| 脚本撰写 | ChatGPT/Claude/通义千问 | 脚本生成、改写、润色 |
| 分镜设计 | Midjourney/DALL-E/Stable Diffusion | 生成概念图、分镜草图 |
| 配音 | ElevenLabs/剪映AI配音/微软TTS | AI语音合成、多语言配音 |
| 字幕 | 剪映/PR字幕/AutoSub | 自动识别并生成字幕 |
| 剪辑 | 剪映/CapCut/Descript | AI自动剪辑、智能裁剪 |
| 画面生成 | Runway/Pika/Sora | AI生成视频片段 |
| 配音克隆 | ElevenLabs/魔音工坊 | 声音克隆、多语种配音 |
| 封面设计 | Canva/美图秀秀AI | AI生成封面图 |
| 数据分析 | 新榜/飞瓜数据AI | 智能分析、趋势预测 |

### 4.2 AI视频制作工作流

```
AI选题分析 → AI脚本生成 → AI分镜设计 → 拍摄 → AI粗剪 → AI精剪 → AI配音/字幕 → AI调色 → AI封面 → 人工审核 → 发布
```

#### AI脚本生成提示词模板

```
你是一位专业的短视频编剧。请根据以下信息生成一条短视频脚本：

主题：[填写主题]
目标平台：[抖音/B站/YouTube]
目标受众：[描述受众]
视频时长：[秒数]
核心观点：[一句话概括]
风格要求：[幽默/专业/温馨/励志]

请按以下格式输出：
1. 标题（3个备选）
2. 开头3秒钩子
3. 正文内容（分镜头描述+台词）
4. 结尾CTA
5. 推荐的BGM类型
6. 标签建议
```

#### AI辅助剪辑工作流

1. **素材导入** → AI自动识别重复/模糊镜头
2. **粗剪** → AI根据脚本自动匹配素材
3. **节奏优化** → AI分析观众留存曲线，建议剪辑点
4. **字幕生成** → AI语音识别生成字幕
5. **BGM匹配** → AI根据内容情绪推荐音乐
6. **封面生成** → AI从视频中提取最佳帧+文字排版

### 4.3 效率提升对比

| 环节 | 传统方式 | AI辅助方式 | 效率提升 |
|------|---------|-----------|---------|
| 脚本撰写 | 2-4小时 | 30分钟 | 80% |
| 字幕制作 | 1-2小时 | 5分钟 | 95% |
| 粗剪 | 2-3小时 | 30分钟 | 85% |
| 封面设计 | 30-60分钟 | 5分钟 | 90% |
| 数据分析 | 1小时 | 5分钟 | 95% |

## 5. 团队协作与项目管理

### 5.1 内容团队角色分工

```
内容总监（1人）→ 负责整体内容方向和品质把控
策划（1-2人）→ 选题调研、脚本撰写
拍摄（1-2人）→ 设备操作、现场调度
剪辑（1-2人）→ 后期制作、特效包装
运营（1人）→ 发布、数据分析、粉丝互动
```

### 5.2 内容日历规划

**每周规划模板：**

| 日期 | 视频主题 | 负责人 | 状态 | 发布时间 |
|------|---------|--------|------|---------|
| 周一 | 选题策划会 | 策划 | ✅ 已完成 | - |
| 周二 | 脚本撰写 | 策划 | 🔄 进行中 | - |
| 周三 | 拍摄 | 拍摄+剪辑 | ⏳ 待开始 | - |
| 周四 | 后期制作 | 剪辑 | ⏳ 待开始 | - |
| 周五 | 审核+发布 | 内容总监 | ⏳ 待开始 | 18:00 |

### 5.3 版本管理

```
素材管理：
├── 原始素材/
│   ├── 20260625_拍摄_镜头01.mp4
│   └── ...
├── 工程文件/
│   ├── project_v1.prproj
│   ├── project_v2.prproj
│   └── project_final.prproj
├── 输出成品/
│   ├── 抖音版_1080x1920.mp4
│   └── B站版_1920x1080.mp4
└── 发布记录/
    └── 发布日志.xlsx
```

### 5.4 质量把控标准

**发布前检查清单：**
- [ ] 画面清晰度 ≥ 1080p
- [ ] 音质无明显杂音
- [ ] 字幕准确率 100%
- [ ] 内容无敏感/违规信息
- [ ] 品牌元素正确使用（Logo/配色/字体）
- [ ] 时长符合平台要求
- [ ] 封面图有吸引力

## 7. 各平台发布策略

### 7.1 抖音

**内容特点：**
- 竖版9:16为主
- 时长15秒-3分钟
- 前3秒决定生死
- 音乐驱动型内容

**发布策略：**
- 日更或隔日更
- 发布时间：12:00-13:00 / 18:00-21:00
- 使用热门BGM和话题标签
- 引导评论区互动

### 7.2 B站

**内容特点：**
- 横版16:9为主
- 时长5-30分钟
- 弹幕文化
- 深度内容受欢迎

**发布策略：**
- 周更2-3条
- 发布时间：18:00-22:00
- 标题要有信息量
- 简介区放相关链接和时间戳

### 7.3 YouTube

**内容特点：**
- 横版16:9
- 时长不限（推荐8分钟以上）
- SEO重要（标题/描述/标签）
- 长尾流量

**发布策略：**
- 固定更新时间
- 优化SEO（关键词研究）
- 使用章节标记
- 鼓励订阅和分享

### 7.4 视频号

**内容特点：**
- 社交推荐机制
- 中老年用户较多
- 实用信息类内容表现好

**发布策略：**
- 转发到朋友圈和社群
- 发布时间：早上7-8点 / 中午12-13点 / 晚上20-22点
- 内容偏向生活实用、健康知识

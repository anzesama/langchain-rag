## ❌ 失败的测试项（6/61）

### 1. AAAMLP-CN 文档可查（Step 6）— 次要问题
- **详情**: `get_chunk_count("AAAMLP-CN")` 返回 0
- **原因**: `get_chunk_count` 使用精确匹配 `where={"source": "AAAMLP-CN"}`，但实际 source 字段是完整路径（如 `documents\AAAMLP-CN\交叉检验.md`）
- **影响**: **无实际影响** — 检索测试（Step 7）证明数据完全可查
- **修复建议**: `get_chunk_count` 应改为模糊匹配（`source LIKE '%AAAMLP-CN%'`）

### 2-5. 问答测试（Step 8）— 外部环境问题
- **详情**: LLM API 被 Cloudflare 拦截（HTTP 403 Forbidden）
- **原因**: agnes-ai.com 的 Cloudflare 安全策略阻止了请求
- **影响**: 仅影响 RAG 问答生成，**不影响知识库本身的加载/检索功能**
- **注意**: 检索功能完全正常，只是无法调用 LLM 生成自然语言回答

## 📝 发现的问题

### 1. Source 路径不一致（次要）
- **现象**: 部分文档 source 为相对路径 `documents\AAAMLP-CN\xxx.md`，部分为绝对路径 `D:\class\project-config\langchain-rag\documents\AAAMLP-CN\xxx.md`
- **原因**: 多次入库导致路径格式不统一
- **影响**: 不影响检索，但影响统计准确性
- **建议**: 统一使用相对路径存储

### 2. LLM API 不可用（外部问题）
- **现象**: Cloudflare 拦截 agnes-ai.com 请求
- **原因**: 服务器端安全策略
- **影响**: 无法生成自然语言回答
- **建议**: 联系 Agnes AI 团队或更换 API 端点

- **现象**: 13 个 chunk 少于 50 字符
- **占比**: 2% (13/630)
- **影响**: 微小，不影响检索质量
- **建议**: 可在 chunk 过滤中增加最小长度检查

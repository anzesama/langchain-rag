# 知识图谱统一管理 — 设计方案

- 日期：2026-07-25
- 分支：`feature/graph-unified-management`
- 状态：设计中

## 目标

将实体管理和关系管理全部合并到知识图谱标签页，图谱成为唯一的 Wiki 数据管理入口。移除"实体管理"和"关系管理"两个独立标签页。

## 交互设计

### 图谱区
| 操作 | 触发 | 行为 |
|------|------|------|
| 添加实体 | [+添加实体] 按钮 | 弹出实体编辑模态框 |
| 添加关系 | [+添加关系] 按钮 | 弹出关系编辑模态框 |
| 编辑实体 | 点击节点 → 右侧面板 [编辑] | 弹出实体编辑模态框，预填数据 |
| 删除实体 | 点击节点 → 右侧面板 [删除] | 确认弹窗，删除后刷新图谱 |
| 选中实体 | 点击图谱节点 | 右侧面板显示实体详情 + 关联关系列表 |
| 删除关系 | 右侧面板关系列表中的 [删除] | 确认后删除关系，刷新图谱 |
| 刷新 | [刷新] 按钮 | 重新加载数据和图谱 |
| 导出 | [导出图片] 按钮 | 导出 PNG |

### 模态框
- **实体编辑模态框**（已有）：名称、类型、属性(JSON)、来源章节
- **关系编辑模态框**（已有）：源实体（下拉选择）、目标实体（下拉选择）、关系类型

### 右侧详情面板
显示选中实体的：
- 基本信息（名称、类型、属性、来源章节）
- [编辑] [删除] 按钮
- 关联关系列表（该实体作为源 or 目标的全部关系），每条有 [删除关系] 按钮

## 需适配的后端 API

已有 API 完全可复用，无需新增：
- `GET /api/entities` — 加载实体
- `POST /api/entities` — 添加实体
- `PUT /api/entities/<id>` — 更新实体
- `DELETE /api/entities/<id>` — 删除实体
- `GET /api/relations` — 加载关系（已含 source_name/target_name）
- `POST /api/relations` — 添加关系
- `DELETE /api/relations/<id>` — 删除关系
- `GET /api/stats` — 统计

## 需要新增的前端函数

| 函数 | 说明 |
|------|------|
| `showEntityDetail(entityId)` | 点击节点后右侧面板显示实体详情 + 关联关系 |
| `getRelatedRelations(entityId)` | 遍历全局 relations 查出该实体所有关联 |
| `editEntityById(entityId)` | 打开编辑模态框预填数据 |
| `deleteEntityById(entityId)` | 确认后删除实体 |
| `deleteRelationById(relId)` | 确认后删除关系 |

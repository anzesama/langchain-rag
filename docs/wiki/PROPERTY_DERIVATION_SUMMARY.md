## 实现内容

### 1. 规则引擎扩展

在 `wiki_reasoner.py` 中新增 4 条属性推导规则：

#### 规则 5: 持有蛊虫→获得功能
- **条件**: X 持有 Y（蛊虫），且 Y 有"功能"属性
- **推导**: X 获得 Y 的功能属性
- **置信度**: 0.8
- **示例**: 方源持有春秋蝉（功能=重生）→ 方源获得能力:重生

#### 规则 6: 持有蛊虫→获得境界
- **条件**: X 持有 Y（蛊虫），且 Y 有"境界"属性
- **推导**: X 获得 Y 的境界信息
- **置信度**: 0.7
- **示例**: 方源持有全力以赴蛊（境界=三转）→ 方源掌握境界:三转

#### 规则 7: 师承→继承流派
- **条件**: X 师承 Y，且 Y 有"主修"属性
- **推导**: X 可能继承 Y 的流派
- **置信度**: 0.5
- **示例**: X 师从 Y（Y主修力道）→ X 可能继承力道

#### 规则 8: 持有流派→获得特点
- **条件**: X 持有/主修 Y（流派），且 Y 有"特点"属性
- **推导**: X 获得 Y 的特点信息
- **置信度**: 0.75
- **示例**: 方源主修力道（特点=真元消耗少、持久战斗）→ 方源获得流派特点

### 2. 新增方法

#### `derive_entity_properties(entity_name: str) -> List[Dict]`
为指定实体推导属性
- 参数: 实体名称
- 返回: 推导出的属性列表
- 实现: 遍历所有规则，检查条件是否满足，执行推导

#### `apply_derived_properties(entity_name: str) -> int`
应用推导的属性到实体
- 参数: 实体名称
- 返回: 应用的属性数量
- 实现: 更新实体的 properties 字段

#### `apply_all_derived_properties() -> Dict[str, int]`
为所有实体应用推导属性
- 返回: 统计信息（总实体数、有推导的实体数、应用的属性总数）
- 实现: 遍历所有实体，调用 apply_derived_properties

### 3. CLI 命令扩展

在 `wiki_cli.py` 中扩展 `cmd_reason` 函数：

#### 新增参数
- `--apply-properties`: 应用推导的属性到实体
- `--entity ENTITY`: 指定实体名称（仅用于属性推导）

#### 使用示例
```bash
# 为指定实体推导属性
python wiki_cli.py reason --apply-properties --entity 方源

# 为所有实体应用推导属性
python wiki_cli.py reason --apply-properties

# 显示详细推导结果
python wiki_cli.py reason --apply-properties --entity 方源 --show-results
```

## 技术特点

### 1. 规则引擎
- 基于条件-推导模式
- 每条规则有明确的条件判断和推导逻辑
- 支持置信度评分

### 2. 属性推导
- 零成本：纯规则实现，无需 LLM
- 低延迟：O(n) 时间复杂度
- 可解释：每个推导都有详细原因

### 3. 属性应用
- 自动去重：不覆盖已有属性
- 事务性：数据库更新失败会回滚

### 4. CLI 交互
- 灵活：支持单个实体或所有实体
- 详细：显示推导过程和结果

## 局限性

### 1. 目标实体属性依赖
- 如果目标实体（如星宿仙尊）没有属性，无法推导出源实体的继承属性
- 解决方案：需要先手动补充目标实体的属性

### 2. 推导置信度
- 部分规则置信度较低（如师承→继承流派，0.5）
- 建议：高置信度规则优先应用，低置信度规则进入待审核队列

### 3. 规则覆盖范围
- 目前只覆盖了 4 条属性推导规则
- 未来可扩展：基于同伴关系、利用关系、敌对关系等推导更多属性

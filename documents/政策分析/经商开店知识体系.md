## 第一部分：经商需要哪些知识

### 一、商业基础知识框架

#### 1. 商业模式设计
- **价值主张**：你为谁解决什么问题
- **收入模式**：怎么赚钱（一次性销售、订阅制、佣金、广告等）
- **成本结构**：固定成本 vs 变动成本
- **关键资源**：人、财、物、技术、品牌
- **关键活动**：生产、营销、配送、服务
- **客户关系**：获取、留存、增购
- **渠道通路**：线上/线下、直营/加盟/代理
- **供应商**：上游合作方的选择与管理

*参考来源：Alexander Osterwalder《商业模式新生代》*

#### 2. 市场调研与分析
- **市场规模**：TAM/SAM/SOM 分析方法
- **目标客群画像**：年龄、收入、消费习惯、痛点
- **竞品分析**：直接竞争者、间接竞争者、替代品
- **SWOT分析**：优势、劣势、机会、威胁
- **PEST分析**：政策、经济、社会、技术宏观环境
- **数据来源**：国家统计局、行业协会报告、艾瑞咨询、易观分析

#### 3. 财务知识 ⭐ 核心
- **三大报表**：资产负债表、利润表、现金流量表
- **关键指标**：
  - 毛利率 = (收入-成本)/收入
  - 净利率 = 净利润/收入
  - 盈亏平衡点 = 固定成本/(单价-单位变动成本)
  - 投资回报率 ROI = (收益-成本)/成本
  - 坪效 = 销售额/营业面积
  - 人效 = 销售额/员工数
- **现金流管理**：
  - 经营性现金流 vs 投资性现金流 vs 筹资性现金流
  - 现金储备至少覆盖6个月固定支出
  - 应收账款账期管理
- **融资渠道**：
  - 自有资金
  - 亲友借款
  - 银行小额贷款
  - 政府创业补贴
  - 天使投资/VC
  - 众筹

#### 4. 法律合规知识
- **市场主体类型**：
  - 个体工商户（无限责任，简单）
  - 个人独资企业（无限责任）
  - 有限责任公司（有限责任，推荐）
  - 股份有限公司（适合大型企业）
- **注册流程**：
  - 核名 → 提交材料 → 领取营业执照 → 刻章 → 银行开户 → 税务登记
  - 全程可网上办理（各地政务服务网）
- **必备证照**：
  - 营业执照（所有经营都需要）
  - 食品经营许可证（餐饮/食品）
  - 烟草专卖许可证（卖烟）
  - 酒类流通备案（卖酒）
  - 卫生许可证（美容/洗浴）
  - 消防验收合格证（面积>300㎡或特殊场所）
  - 环保审批（有污染排放）
- **税务知识**：
  - 增值税（小规模纳税人3%/一般纳税人13%）
  - 企业所得税（小微企业优惠）
  - 个人所得税（经营所得）
  - 印花税、城建税等附加税
  - 月度/季度申报义务
- **劳动法规**：
  - 劳动合同签订（入职一个月内）
  - 社保缴纳（五险）
  - 最低工资标准
  - 加班费规定
  - 解雇补偿

#### 5. 营销与销售
- **品牌定位**：差异化、记忆点、口号
- **4P理论**：产品(Product)、价格(Price)、渠道(Place)、促销(Promotion)
- **获客渠道**：
  - 线上：抖音/快手/小红书/微信/淘宝/美团/饿了么
  - 线下：门店招牌、社区活动、地推
- **私域运营**：微信群、公众号、小程序
- **会员体系**：积分、等级、储值卡
- **定价策略**：
  - 成本加成定价
  - 竞争导向定价
  - 价值定价
  - 渗透定价（低价入市）
  - 撇脂定价（高价入市）

#### 6. 产品与服务管理
- **供应链管理**：选品、采购、仓储、物流
- **质量控制**：ISO标准、行业规范
- **库存管理**：
  - ABC分类法
  - 安全库存计算
  - 先进先出(FIFO)
  - 盘点频率（日盘/周盘/月盘）
- **售后服务**：退换货政策、投诉处理流程

#### 7. 团队与管理
- **组织架构**：扁平化 vs 层级制
- **招聘流程**：JD撰写 → 面试 → 试用期 → 转正
- **薪酬设计**：底薪+绩效+提成+奖金
- **培训体系**：入职培训、技能提升、管理培训
- **绩效考核**：KPI、OKR、360度评估
- **企业文化**：使命、愿景、价值观

## 第二部分：开店需要哪些知识

### 一、选址决策 ⭐⭐⭐ 开店最关键

#### 选址评估体系
- **商圈类型**：
  - 社区商圈（居民消费，稳定）
  - 写字楼商圈（白领消费，午晚高峰）
  - 商业中心商圈（人流大，租金高）
  - 交通枢纽商圈（机场/车站，一次性消费多）
  - 校园商圈（学生消费，价格敏感）
- **人流分析**：
  - 分时段统计（早/中/晚/工作日/周末）
  - 有效客流 vs 无效客流（路过≠进店）
  - 步行速度（慢速街区更适合停留消费）
- **可视性与可达性**：
  - 门头是否醒目
  - 是否在一楼/临街
  - 停车便利性
  - 公共交通距离
- **租金合理性**：
  - 租金占比建议：< 预期月收入的15%
  - 押付方式：通常押二付三或押三付六
  - 免租期：争取1-3个月装修免租
- **竞品分布**：
  - 同类店铺距离（太近恶性竞争，太远证明市场不大）
  - 互补业态（咖啡馆旁边开书店是好事）
- **政策风险**：
  - 拆迁规划
  - 道路施工
  - 交通管制

## 第三部分：常见开店类型与特别注意事项

### 1. 餐饮店
- **核心难点**：食品安全、口味稳定性、翻台率
- **必备证照**：食品经营许可证、健康证
- **关键指标**：食材成本率<35%、人工成本率<20%、租金率<15%
- **风险提示**：餐饮倒闭率高达60%

### 2. 零售店（便利店/超市）
- **核心难点**：选品、库存周转、供应链
- **关键指标**：库存周转率>8次/年、坪效>5000元/㎡/年
- **风险提示**：电商冲击严重，需差异化

### 3. 美容美发/美甲
- **核心难点**：技师流失、客户复购
- **必备证照**：卫生许可证
- **关键指标**：客户留存率>60%、客单价>200元
- **风险提示**：人员管理是关键

### 4. 教育培训
- **核心难点**：师资、场地合规、预收款监管
- **必备证照**：办学许可证（学科类）、消防验收
- **关键指标**：续费率>70%、满班率>80%
- **风险提示**：政策监管严格

### 5. 咖啡店/奶茶店
- **核心难点**：选址、产品差异化、复购率
- **关键指标**：日均杯数>100杯、毛利率>60%
- **风险提示**：竞争激烈，同质化严重

### 6. 健身房
- **核心难点**：获客成本、会员卡退款、教练管理
- **必备证照**：高危险性体育项目经营许可证
- **关键指标**：会员留存率>50%、坪效>3000元/㎡/年
- **风险提示**：预付费模式监管趋严

## 第五部分：政府扶持政策（2025-2026）

*参考来源：商务部、人社部、各地政务服务网*

### 1. 创业补贴
- 一次性创业补贴：5000-20000元（各地不同）
- 创业担保贷款：最高50万，贴息50%
- 社保补贴：招用就业困难人员，补贴社保

### 2. 税收优惠
- 小微企业增值税减免
- 个体工商户定额征收
- 重点群体创业税收扣减

### 3. 场地支持
- 创业孵化器免费/低价工位
- 政府认定的创业园区租金补贴

### 4. 培训支持

- 师带徒补贴

### 5. 申请渠道
- 当地政务服务网
